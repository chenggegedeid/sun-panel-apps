# 更新日志

## 3.0.3 — 2026-11-27

**歌词默认就显示**

- 歌词改由播放器统一加载：一开始播放就在后台取歌词，卡片上的歌词不再依赖主窗口是否打开（以前要先打开窗口或点开歌词页才会同步）
- 取到的歌词按「服务器 + 歌曲」缓存，重播同一首不再重复请求
- 主窗口的歌词面板和卡片共用同一份歌词，少一次请求

**修正**

- 歌词面板打开时没有定位到当前这句（停在开头，高亮行贴在底部）：改为打开就跳到当前行居中，之后跟随播放平滑滚动
- 示例数据里带敏感词的专辑名换成 Lorde《Melodrama》

## 3.0.2 — 2026-11-27

**全新卡片视觉**

- 卡片改为沉浸式：封面铺满整卡 + 渐变遮罩 + 底部文字，不再是一块色底加一角封面
- 遮罩深浅跟着封面亮度走（浅色封面自动加深），标题在任何封面上都看得清
- 播放键 / 上一首 / 下一首换成矢量图标，按钮带毛玻璃底，不再是文字符号

**修正**

- 通栏卡片（1xfull）重做：封面做虚化底纹，左侧封面 + 曲名 / 歌手，中间显示当前歌词，右侧时间与上一首/播放/下一首，底部一条细进度线
  - 原来 76px 的封面在矮卡片里被裁掉一半、文字块从卡片顶部溢出，现已改为按卡片高度自适应
  - 原来横向遮罩是「左浅右深」，文字却排在左边，浅色封面上标题会看不清，方向已修正
- 2x1 卡片左侧留了 76px 空位却没有封面，已补上
- 1x1 的播放符号改成矢量图标，封面做虚化底纹

## 3.0.1 — 2026-11-27

**修复**

- 简听模式打开就显示「没有找到歌曲」：默认列表标签沿用了 Subsonic 的 `newest`，简听没有这个榜单，直接返回空且不发请求。现在切换到某个服务时会自动对齐到它支持的第一个标签，未知标签统一兜底到「每日推荐」
- 卡片不显示歌词：播放器新增 `lyricLine` 状态，窗口解析出当前歌词行后同步给卡片，标题下方会多显示一行歌词

## 3.0.0 — 2026-11-27

**新增音乐服务：简听（music-downloader）**

- 支持接入自建「简听」音乐站，与 Subsonic 并列成为可选服务类型
- 简听模式提供：每日推荐、飙升榜 / 新歌榜 / TOP 榜、曲库搜索、同步歌词
- 播放地址每次实时申请（简听的签名地址约 9 分钟失效），队列只存歌曲本身
- token 自动续期：失效后静默重新登录，用户无感

**架构：服务注册表**

- 新增 `src/utils/provider.js`，每种音乐服务是一个 provider 对象
- 界面不再关心底层协议，新增服务只需实现 ping / list / play / cover / lyrics
- 以后接入网易云、QQ 音乐、Emby、Plex、本地目录等，加一个文件即可，不动界面代码

**其他**

- 配置页新增「服务类型」下拉，地址占位符随类型变化
- 播放器支持「歌曲列表」视图（无专辑结构的服务）
- 网络请求继续走 `api.network.request`，应用侧零 `fetch`

## 2.0.1 — 2026-11-27

**修复**

- 封面一直闪烁：`coverUrl` 每次调用都会生成新的随机 salt，界面重渲染时图片地址不断变化，导致浏览器反复重新下载
  - 现在按「服务器 + 封面 + 尺寸」缓存地址，同一张封面在多次渲染中保持一致
- 服务器缺少封面时显示浏览器的「破图」图标 —— 改为回退到音符占位图
- 整页每 240ms 随播放进度重绘一次 —— 改为限流到约 800ms，封面与列表不再频繁重排

## 2.0.0 — 2026-11-27

**本次为规范整改版本**

- 网络请求全部改用平台提供的 `api.network.request`（网络透传），移除原生 `fetch`，产物中应用侧 0 处 `fetch`
- `app.config.js` 声明 `network` 权限，并放开域名白名单（目标服务器由用户填写）
- 请求交由宿主转发，浏览器侧不再携带 Cookie，跨域限制随之消失
- 保持 1.2.0 的全部功能：播放模式、音量、快捷键、MediaSession、同步歌词

## 1.2.0 — 2026-11-27

**新增**

- 播放模式：顺序 / 单曲循环 / 随机，播放条左侧按钮切换，选择会被记住
- 音量控制：播放条右侧滑块，音量同样会被记住
- 键盘快捷键：`空格` 播放暂停、`←` `→` 上一首/下一首、`Shift + ←/→` 快进快退 10 秒、`L` 显示歌词
- 系统媒体控制：接入 MediaSession，支持键盘媒体键和锁屏播放控制

**优化**

- 歌词浮层改为不透明渐变，修复底层专辑详情透出造成的重影
- 歌词手动滚动时暂停自动跟随 5 秒，不再抢滚动
- 进度条拖动改为「松手才跳转」，不再和播放进度互相拉扯

**修复**

- 卡片在 2x1 尺寸下文字被挤压成省略号
- 保存配置时报 `microAppId` 未定义，导致服务器配置整份丢失
