# 更新日志

## 1.2.0 — 2026-11-27

**手机适配**

- `1xfull` 卡片在手机宽度（320–430）下从「一行六指标」改成「名字 / 指标 / 曲线」三段，指标按宽度自动留 2 或 3 个，不再挤成一团
- 主窗口窄屏（< 560）重排：KPI 两列、趋势图固定高度、主页改成整页滚动（原来用 flex 撑满会把下面的卡片压上来重叠）
- 站点与封禁列表在手机上改成逐行卡片：名称 / 域名 / 状态在左，开关或解封按钮贴右，不再挤出屏幕
- 设置页窄屏：服务器名独占一行，地址与令牌全宽，按钮换行成一行三个；输入框字号提到 16px（iOS 上小于 16 会触发页面自动放大）
- 切换条和标签栏在窄屏横向滑动，不再折成多行

**修复**

- 在另一台设备上改了默认服务器，已打开的页面不会更新：现在切回页面时重读一次配置
- 「这张卡片」下拉下方的说明会写明当前是「跟随默认」还是「锁定某台」，避免改了默认却没反应

## 1.1.2 — 2026-11-27

**新增**

- 每个服务器旁边加了「诊断」按钮：一键打出真实请求，显示实际 URL、状态码、content-type、响应开头，并直接给出结论（接口正常 / 返回的是网页 / 面板代理失败 / 内容不是 Gately）。「连上了但数据不对」时不用再猜

**修复**

- 认不出 Sun-Panel 自己的代理错误：面板连不上目标时会返回 200 + `{"code":-1,"data":{"sun_pan*_template_proxy_error…"}}`，以前被当成「地址填错」，现在明确说是面板侧连不上，并提示常见原因（域名只有 IPv6 而面板没有 IPv6 出口、端口不可达）

## 1.1.1 — 2026-11-27

**修复**

- 「Gately 返回 HTTP 200」这种看不懂的报错：地址填成网页时（Gately 前端是单页应用，路径不对不会 404，而是把首页 HTML 以 200 返回），现在会说清「接口返回 200，但内容不是 Gately 的接口数据（返回的是网页，标题「…」）」并提示检查子路径
- 地址连到了别的服务、返回的 JSON 字段不对时，直接报「不像 Gately」，不再显示成一排 `—`
- 服务器名很长时会把顶部右侧的按钮挤到下一行、甚至撑出窗口，现在超长自动省略
- 设置里改了当前这台的地址或令牌后，证书 / 封禁 / 日志仍显示旧机器的数据
- 打开主窗口时页面数据重复拉了一遍
- 卡片报错时看不出是哪一台，现在错误态也显示服务器名

## 1.1.0 — 2026-11-27

**多台服务器**（本次主要内容）

- 设置页改成服务器清单：最多 8 台，每台有名字、地址、令牌，逐台「测试」看 6 项权限
- 卡片绑定一台服务器：同时盯三台就摆三张卡，各显示各的；绑定时可选「跟随默认」
- 卡片与窗口标题改用**用户起的名字**，不再显示 `debian` 这类主机名；主机名退到副标题
- 主窗口顶部服务器切换条，带在线状态点和实时 QPS，切换时下面五个标签页一起换
- 每台独立轮询与缓存，切回去不用重新等；窗口打开时所有台一起挂上，切换条才有实时数字
- 旧版单实例配置自动迁移成清单第一台，不用重填
- 状态仓库从单例改成「每台一份」，多张卡片引用同一台时仍只发一轮请求

**修复**

- 趋势图的 x 轴时间标签不跟数据走（`trend` 没注册成响应式属性，一直渲染旧的兜底曲线）
- 切换 30/60/120 分钟时趋势不重新拉取
- 启停站点后趋势不重算（原来调了已删除的方法）
- 证书到期时间读的是不存在的 `info` 字段——真实接口只给 `certPem`，改为在浏览器里解析 X.509，取有效期与 SAN 域名
- 毫秒时间戳被当成秒，到期日期会显示成几万年后
- 设置页保存后已打开的卡片不切换服务器
- 服务器全删光时主窗口仍显示上一台的数字
- 「移除」依赖 `confirm()`，在面板窗口里常被拦掉、看起来点不动，改成行内二次确认
- 多台时只有当前台在轮询，切换条上其它台没有状态

## 1.0.0 — 2026-11-27

首个版本：把自托管网关 Gately 的运行状态装进导航页。

**卡片（七种尺寸）**

- `1x1` `1x2` `2x1` `2x2` `2x4` `4x4` `1xfull` 逐个排版，不是简单缩放
- 指标可自选可排序：请求速率、实时带宽、处理中、站点、封禁 IP、拦截、CPU、内存、累计请求
- 趋势曲线：自动 / 只看带宽 / 只看 QPS / 不显示，曲线从 0 起算，不画假基线
- 三种底色（透明 / 毛玻璃 / 纯色），圆角、不透明度、文字颜色、强调色均可调
- 深浅色自动适配，浅色壁纸下指标小块改用深色底，不会糊成一片
- 窄卡片（`1x1` `1x2`）走容器查询切单列，文字不会被裁

**主窗口**

- 概览：四个 KPI、30/60/120 分钟趋势图（含 5xx 虚线）、主机与进程、进程排行、四个入口卡
- 站点：上游健康、请求数、QPS，右侧开关直接启停
- 证书：到期进度条与剩余天数，一键续期
- 封禁：手动封禁表单 + 名单 + 解封
- 日志：按级别着色
- 每个功能旁都能直接跳 Gately 后台对应页面（hash 路由）
- 窗口拉高时趋势图自动吃掉剩余高度，底部不会留一片空白

**连接**

- 请求走宿主网络透传（`api.network.request`），不受同源限制，反代不用配 CORS
- 地址归一化：自动补协议、按端口猜 http/https、剥掉 hash 与结尾斜杠、保留子路径
- 配置页「测试连接」逐项探测 6 个读权限域，缺哪个一眼看出来
- 读权限与写权限分离，只读令牌也能完整看监控
- 模块未启用（403）时降级为空态并说明原因，不会整页报错
- 页面切到后台（`document.hidden`）时暂停轮询，回来立刻补一次
