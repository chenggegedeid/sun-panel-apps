# 更新日志

## 1.0.0 — 2026-11-27

首个版本：把自托管网关 Gately 的运行状态装进导航页。

**卡片（七种尺寸）**

- `1x1` `1x2` `2x1` `2x2` `2x4` `4x4` `1xfull` 逐个排版，不是简单缩放
- 指标可自选可排序：请求速率、实时带宽、处理中、站点、封禁 IP、拦截、CPU、内存、累计请求
- 趋势曲线：自动 / 只看带宽 / 只看 QPS / 不显示，曲线从 0 起算，不画假基线
- 三种底色（透明 / 毛玻璃 / 纯色），圆角、不透明度、文字颜色、强调色均可调
- 深浅色自动适配，浅色壁纸下指标小块改用深色底，不会糊成一片
- 窄卡片（`1x1` `1x2`）走容器查询切单列，文字不会被裁

**主窗口**

- 概览：四个 KPI、30/60/120 分钟趋势图（含 5xx 虚线）、主机与进程、进程排行、四个入口卡
- 站点：上游健康、请求数、QPS，右侧开关直接启停
- 证书：到期进度条与剩余天数，一键续期
- 封禁：手动封禁表单 + 名单 + 解封
- 日志：按级别着色
- 每个功能旁都能直接跳 Gately 后台对应页面（hash 路由）
- 窗口拉高时趋势图自动吃掉剩余高度，底部不会留一片空白

**连接**

- 请求走宿主网络透传（`api.network.request`），不受同源限制，反代不用配 CORS
- 地址归一化：自动补协议、按端口猜 http/https、剥掉 hash 与结尾斜杠、保留子路径
- 配置页「测试连接」逐项探测 6 个读权限域，缺哪个一眼看出来
- 读权限与写权限分离，只读令牌也能完整看监控
- 模块未启用（403）时降级为空态并说明原因，不会整页报错
- 页面切到后台（`document.hidden`）时暂停轮询，回来立刻补一次
