# 更新日志

## 2.0.0 — 2026-11-27

**版本号与音乐应用对齐，便于统一维护**

- 包含 1.1.1 的全部内容：农历生日 / 农历纪念日、删除事件二次确认
- 事件行控件自适应换行，窄窗口不再挤压

## 1.1.1 — 2026-11-27

**新增**

- 删除事件需点两次（第一次变成「确认删除」，3 秒内再点才生效），避免误删生日这类长期事件

**优化**

- 事件行控件自动换行，窄窗口下不再挤压
- 配置页深浅色适配补齐（公历/农历切换、下拉框）

**修复**

- 农历小月没有三十时，倒计时会取错年份（现自动顺延到有三十的年份）

## 1.1.0 — 2026-11-27

**新增**

- 农历生日 / 农历纪念日：事件可切换公历/农历，农历按「月 + 日」每年重复
- 自动换算公历日期并回推校验，闰月不误判
- 卡片与「即将到来」列表对农历事件优先显示农历日期

## 1.0.3 — 2026-11-27

- 修复保存配置时报 `microAppId` 未定义
- 卡片配置存进数据节点，`widget.save` 失败也不再丢配置

## 1.0.2 — 2026-11-27

- 配置页深色模式看不到文字的问题
- 配置页底色改为自带，不再依赖宿主窗口背景

## 1.0.1 — 2026-11-26

- 七种尺寸布局微调，透明背景在深色壁纸下更清楚

## 1.0.0 — 2026-11-26

- 首个版本：背景真透明的日历 / 倒计时卡片，支持农历、节气、内置节日与自定义纪念日
